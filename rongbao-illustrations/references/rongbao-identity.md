# 绒宝媒介无关身份协议

这份协议是跨设计 Skill 的身份层。它只规定绒宝是谁，不规定最终媒介、画幅或输出风格；正文配图的白底极简手绘规则仍由本 Skill 的原生模式负责。

## 固定身份锚点

组合到其他设计 Skill 时，除非用户明确要求改变角色设定，必须保留：

- 黄色圆形主体。
- 两片青绿色叶耳。
- 大棕黑眼睛，保留白色眼白和简洁高光。
- 橙色腮红。
- 橙色手和橙色脚。

`assets/rongbao.webp` 是本 Skill 的角色参考图。组合生图时必须把它作为角色参考图传给目标设计 Skill；只读取上述身份锚点，不把它默认为背景、材质、光线或姿态参考。

## 身份层与媒介层

身份层固定绒宝的识别信息：身份色默认保持鲜亮黄、鲜亮青绿和鲜亮橙。只有环境或用户明确要求时，才允许因局部受光、遮挡或材质反射做局部变化；禁止用综合色偏、统一降饱和或复古做旧来伪装融合。

媒介层由目标设计 Skill 决定：角色材质、笔触、边缘、颗粒、环境光和投影必须适配目标 Skill 的基础媒介与融合媒介。媒介变化可以改变角色的表现方式，但不能抹掉身份层，也不得把目标场景的风格规则强行改成正文白底手绘。

## 媒介融合约束

不得保留参考图的摄影棚 3D 绒毛、硬抠边缘或独立高光，导致角色像贴片一样浮在水墨、矿物颜料或其他场景上；角色与场景必须共享同一套媒介和光线逻辑。禁止用综合色偏、统一降饱和、复古做旧或全局滤镜替代真正的媒介融合。

## 媒介转换示例

这些是可迁移的转换模板，不限定目标 Skill 只能使用这三种媒介：

- **水墨**：保留鲜亮黄/青绿/橙作为局部身份色块；把角色边缘转为与场景相同的墨线和晕染，使用同一纸面颗粒、环境光和投影，不保留 3D 绒毛高光。
- **版画**：保留鲜亮身份色作为套印色块；让角色轮廓与场景共享刻线、套色错位和纸张颗粒，阴影方向与背景一致，不用抠图边缘。
- **折纸**：保留鲜亮身份色对应的纸面分区；把角色材质转为与场景一致的折痕、折面边缘和接触阴影，角色和道具共享同一光源，不保留毛绒体积感。

## 目标设计 Skill 的边界

目标设计 Skill 契约优先决定：

- 画幅和比例：横版、竖版或方图。
- 构图、空间层级和视觉重心。
- 材质、笔触、光线、色彩系统和完成度。
- 文字、排版和标注策略。
- 输出格式、尺寸、保存位置和交付方式。

本 Skill 的纯白背景、黑色手绘线稿、留白和少量中文批注，只是正文插图原生模式的默认值，不得强行覆盖封面、竖版海报或方图目标 Skill 的设计契约。

## 组合优先级

发生冲突时，按以下顺序处理：

1. 用户明确要求。
2. 目标设计 Skill 契约。
3. 绒宝身份锚点。
4. 本 Skill 的 adapter 默认值。

如果用户明确要求改变某个身份锚点，应把该改变透传给目标 Skill，并在交付说明中标明；不要擅自用本 Skill 的默认风格替换目标 Skill 的输出。
